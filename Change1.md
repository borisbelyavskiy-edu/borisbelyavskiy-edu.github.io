# Change 1: Design and Visibility Improvements

## Goals

Improve the portfolio's design and make its content easier to notice, scan, and read. The homepage should establish a stronger visual hierarchy, use available width more effectively, and remain clear on both desktop and mobile screens.

## Tasks completed

- Expanded the homepage hero headline to use the full content width.
- Moved the “Currently exploring” prompt below the main hero copy.
- Widened the text areas in the first and second homepage sections.
- Increased the size of section indexes, pathway numbers, and key metrics to strengthen hierarchy.
- Replaced the previous green accents with a palette built around dark blues, light lavender surfaces, and purple accents.
- Updated the favicon to match the revised palette.
- Checked the page at desktop and mobile widths for headline wrapping and layout behavior.

## Verification

- The Jekyll site built successfully.
- Desktop and mobile Lighthouse checks each scored 100 for Performance, 100 for Best Practices, and 100 for SEO; Accessibility scored 94.
